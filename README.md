# 窝牌计算器 Ver 1.0.0

太平洋前线（Pacific Front）摆阵助手：在据点摆牌页穷尽计算阵容，一点结果就把牌（和道具）摆上。手动计算**不会帮你点「战斗」**，开战由你自己决定。黄色「自动化窝牌」会按规则选点、放牌并点击「战斗」（见下文）。


## 怎么用

1. **打开** `PacificFrontHelper.exe`（窝牌计算器）
2. **进行脚本注入**
   - 打开游戏网页（可用「一键开启窝牌」）
   - 在助手里点「复制注入脚本」
   - 游戏页按 **F12** 打开控制台，粘贴后回车
3. **进入战斗页面**（据点摆牌页，四路空位）
4. **进行计算**
   - **无道具计算**：不带道具进行穷尽计算
   - **带道具计算**：进入道具界面勾选参与计算的道具后，按照你选择的道具进行穷尽计算
5. **等待计算完毕后选择一个阵容**，牌会自动摆好
6. **检查阵容是否正确**，再点游戏里的 **战斗**

手动「无道具计算 / 带道具计算」和点阵容放牌的行为与以前相同，不会开战。


## 自动化窝牌

1. 先完成上面的脚本注入，并打开行动里的据点页。
2. 点黄色 **自动化窝牌**。结果区会改成战斗进程：预测的下一场据点与敌方战力合计、三个行动 / 当前行动据点进度（可从打到一半的行动接着算）、运行时间（精确到秒）。
3. 助手维护内存里的据点 buff 缓存：先打掉会削减敌方增益或我方减益的据点，再在可选据点里选敌方战力合计最低的。阶段摧毁数量已经够了、但还要点的过渡战斗，只放一张自己战力最低的牌。
4. 每场优先无道具、取最低溢出的 100% 阵容；不够再在综合胜率前 50 组上只挂「该卡最高属性对应的那一档可购买训练」；仍不够再算不可购买道具；还不够就用可购买结果里的最优可用阵容开战。
5. 行动最后一个据点若奖励里有进度分（`adeck_progress_points`），算完牌后把可购买的 **效率提升** 挂到这些目标上再开战。这些车道不参与可购买战斗道具穷尽。
6. 正常打完，或点 **停止计算**（会同时停下自动化），都会弹出同一套汇总：运行时间、各行动末阶段进度代币全额 / 未获、简要奖励。关闭按钮在弹框下方居中，没有窗口标题栏的关闭按钮。

改过 `bridge/inject.js` 之后，游戏页需要重新在 **F12** 粘贴一次注入脚本，旧脚本不会自动升级。

自动化只做放牌和点击文案为「战斗」的按钮，不会去点购买、发帖或账号设置。开战不会调用 `keypoint/start` 接口，而是点页面上的战斗按钮；若按钮文案对不上，或切据点时页面整页刷新把注入脚本冲掉，需要你手动点开据点并重新粘贴脚本。
