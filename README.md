# 窝牌计算器 Ver 1.0.0

太平洋前线（Pacific Front）摆阵助手：在据点摆牌页穷尽计算阵容，一点结果就把牌（和道具）摆上。**不会帮你点「战斗」**，开战由你自己决定。

## 功能概览

- 连接游戏页（脚本注入）并采数
- **无道具计算** / **带道具计算**（按你勾选的战斗道具穷尽）
- 结果卡展示综合胜率与溢出；悬停查看四路详情
- 点击结果 → **代码放牌**（不拖鼠标、不调开战接口）
- 道具筛选、程序设置（预存条数、不透明度、桥接端口等）

## 怎么用

1. **打开** `PacificFrontHelper.exe`（窝牌计算器）
2. **进行脚本注入**
   - 打开游戏网页（可用「一键开启窝牌」）
   - 在助手里点「复制注入脚本」
   - 游戏页按 **F12** 打开控制台，粘贴后回车
3. **进入战斗页面**（据点摆牌页，四路空位）
4. **进行计算**
   - **无道具计算**：不带道具进行穷尽计算
   - **带道具计算**：进入道具界面勾选参与计算的道具后，按照你选择的道具进行穷尽计算
5. **等待计算完毕后选择一个阵容**，牌会自动摆好
6. **检查阵容是否正确**，再点游戏里的 **战斗**

## 说明

- 必须在**据点摆牌页**采数与放牌；大厅或错页会缺敌方数据或放不上。
- 系统提示显示在模式按钮上方那一行；悬停可看全文。
- 「停止计算」可中断当前求解。
- 换新版本：关掉旧助手 → 开新 EXE → 重新粘贴一次注入脚本。

## 从源码运行（开发）

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Windows 打包：

```bat
build\build_windows.bat
```

产物：`dist\PacificFrontHelper\PacificFrontHelper.exe`（窗口显示名：**窝牌计算器** Ver 1.0.0）
