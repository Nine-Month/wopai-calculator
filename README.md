# 窝牌计算器 Ver 1.0.0

太平洋前线（Pacific Front）摆阵助手：在据点摆牌页穷尽计算阵容，一点结果就把牌（和道具）摆上。**不会帮你点「战斗」**，开战由你自己决定。


## 怎么用

1. **打开** `PacificFrontHelper.exe`（窝牌计算器）
2. **进行脚本注入**
   - 打开游戏网页（可用「一键开启窝牌」）
   - 在助手里点「复制注入脚本」
   - 游戏页按 **F12** 打开控制台，粘贴后回车
3. **进入战斗页面**（据点摆牌页，四路空位）
4. **进行计算**
   - **无道具计算**：不带道具进行穷尽计算
   - **带道具计算**：进入道具界面勾选参与计算的道具后，按照你选择的道具进行穷尽计算
5. **等待计算完毕后选择一个阵容**，牌会自动摆好
6. **检查阵容是否正确**，再点游戏里的 **战斗**
